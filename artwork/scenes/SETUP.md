# Оформление OBS

Геометрия — layout.json, готовые WEBP — корневой dist/artwork/scenes. Размеры: 2560×1440 и 1080×1920. Используются светлая палитра, Unbounded 400 для заголовков и акцентов, Unbounded 600 только для фирменного никнейма и системный Arial для основного текста; пустые горизонтальный и вертикальный фоны фирменные синие.

Сборка из корня: `bun run render:scenes`. В OBS выбирать WEBP непосредственно из dist/artwork/scenes. Источники камеры, чата, музыки, донатеров и оповещений остаются отдельными. Для статусных сцен после экспорта отдельно выставить их трансформации по картам `horizontal-status` и `vertical-status`; экспорт сам OBS не изменяет.

В статусных сценах фон синий, плашка заголовка светлая, текст заголовка чёрный, над линией — белый никнейм. Слева в плашке стоит скруглённая марка `logo/logo.png` высотой 0.6em, слово начинается через 0.3em; высота плашки — 1.15em, поэтому её верхний и нижний края равноудалены от оптической полосы строчных (0.3em сверху и снизу), и выносные элементы (`у`, `ц`) не касаются края. Донатеры, чат и соцполоса расположены стык в стык и имеют одинаковую ширину; ниже остаётся музыка, отдельно — alerts и QR. Фон чата непрозрачный с прямыми углами, донатеры и соцполоса рисуются отдельными виджетами. У донатеров скруглены ТОЛЬКО верхние углы; соцполоса во всех сценах одна и та же — без скруглений (один источник виджета, переиспользуемый в каждом входе). Не запекайте данные виджетов в фон.

Сцена камеры не имеет запечённого HUD: её фон прозрачный, камера, чат, музыка, донатеры, оповещения и соцполоса остаются отдельными источниками, а QR-код добавляется в OBS вручную. В gameplay-фонах QR не запекается: горизонтальный и вертикальный захват игры закрывает нижнюю половину холста, поэтому код там не сканируется, а без игры он не нужен — QR остаётся только в статусных сценах. Gameplay-фон остаётся прозрачным для игры. Для всех карт `donors` — полный viewport общего источника 1000×134 с одинаковым масштабом по обеим осям; внутренняя панель занимает нижние 114 px, а верхние 20 px прозрачны. Нижний край viewport и панели в статусных и gameplay-картах стыкуется с камерой или чатом; в камерной сцене OBS донатеры стоят вплотную к камере при масштабе 1,28. Размеры источника и настройки провайдера менять не требуется. У chatFit alignment=5 задаёт якорь, boundsAlignment=9 — выравнивание содержимого; это разные параметры. Музыкальный виджет и донатеры не встраиваются в фон.

### Отдельные browser inputs соцполосы

Все browser inputs используют `file:///C:/Users/maseaaao/Projects/maseaaao.tv/dist/obs-widgets/social-strip/index.html` в поле URL. Для разных размеров используются отдельные источники:

| Применение                        | Viewport источника |
| --------------------------------- | ------------------ |
| Горизонтальные статусные сцены    | 640×55             |
| Вертикальные статусные сцены      | 720×88             |
| Шесть горизонтальных игровых сцен | 480×36             |
| Горизонтальная камера             | 1080×55            |
| Вертикальная gameplay             | 1080×88            |

В шести игровых сценах колонка шириной 480 px состоит из донатеров, камеры, соцполосы и музыки, расположенных друг под другом. Отступ от края холста не менее 32 px. Все шесть сцен используют одинаковые источники и переход Move; координаты каждой сцены приведены в `gameplay.horizontal`. В горизонтальной камерной сцене источник 1080×55 равномерно увеличен до ширины 1280 px; Move override сопоставляет его с игровым источником 480×36. Вертикальная соцполоса находится непосредственно под камерой. Анимация соцполосы выполняется CSS виджета.

`donors` — полный viewport 1000×134 с равномерным масштабом, `donorVisible` — панель после прозрачных верхних 20 px. Музыка остаётся отдельным event-managed виджетом и при отсутствии события прозрачна. Игровой захват в вертикальной сцене сохраняет crop и bounds.

Перед установкой: свежий read-only аудит, резервная копия, проверка общих источников и отсутствия эфира/записи, затем установка и readback геометрии и порядка слоёв. Установленную конфигурацию этого прохода читать из приватного журнала и бэкапа; координаты дробные, OBS может квантовать bounds. Верхние скругления донатеров применяются через provider CSS `dist/obs-widgets/donors/donationalerts-stream-stats.css` — его нужно вставить в Stream Stats донат-сервиса вручную.

После обновления проверить отображение в работающем OBS. Сборка экспортов не изменяет коллекции сцен и не запускает эфир.

HTML собираются Vite/singlefile в `dist/artwork/html/scenes`. Для локального
просмотра: `bun run build:artwork`. Редактируемый CSS — obs-scene.css;
изображения OBS находятся в `dist/artwork/scenes/`.
