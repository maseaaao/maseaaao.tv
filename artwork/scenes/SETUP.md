# Оформление OBS

Геометрия — layout.json, готовые WEBP — корневой dist/artwork/scenes. Размеры: 2560×1440 и 1080×1920. Используются светлая палитра, Unbounded 400 и системный Arial; пустые горизонтальный и вертикальный фоны фирменные синие.

Сборка из корня: `bun run render:scenes`. В OBS выбирать WEBP непосредственно из dist/artwork/scenes. Источники камеры, чата, музыки, донатеров и оповещений остаются отдельными. Для статусных сцен после экспорта отдельно выставить их трансформации по картам `horizontal-status` и `vertical-status`; экспорт сам OBS не изменяет. Camera-исходники используют карты `horizontal-camera` и `vertical-camera`; в OBS установлены описанные ниже значения.

В статусных сценах фон синий, плашка заголовка светлая, текст заголовка чёрный, над линией — белый никнейм. Донатеры, чат и соцполоса расположены стык в стык и имеют одинаковую ширину; ниже остаётся музыка, отдельно — alerts и QR. Фон чата непрозрачный с прямыми углами, донатеры и соцполоса рисуются отдельными виджетами. У донатеров скруглены ТОЛЬКО верхние углы; соцполоса во всех сценах одна и та же — без скруглений (один источник виджета, переиспользуемый в каждом входе). Не запекайте данные виджетов в фон.

Сцены камеры сохраняют прозрачные зоны для камеры и динамических виджетов, находящихся под HUD. В вертикальной камерной сцене синяя подложка начинается под соцполосой и проходит под чатом, музыкой и alerts: эти виджеты расположены выше HUD, поэтому их содержимое не перекрывается. Gameplay-фон остаётся прозрачным для игры. Для всех карт `donors` — полный viewport общего источника 1000×134 с одинаковым масштабом по обеим осям; внутренняя панель занимает нижние 114 px, а верхние 20 px прозрачны. Нижний край viewport и панели в статусных, камерных и gameplay-картах стыкуется с камерой или чатом. Для горизонтальной и вертикальной камеры масштабы — 1,28 и 1,08 соответственно; размеры источника и настройки провайдера менять не требуется. У chatFit alignment=5 задаёт якорь, boundsAlignment=9 — выравнивание содержимого; это разные параметры. Музыкальный виджет и донатеры не встраиваются в фон.

### Отдельные browser inputs соцполосы

Все browser inputs используют `file:///C:/Users/maseaaao/Projects/maseaaao.tv/dist/obs-widgets/social-strip/index.html` в поле URL. Для разных размеров используются отдельные источники:

| Применение                                         | Viewport источника |
| -------------------------------------------------- | ------------------ |
| Горизонтальные статусные сцены                     | 640×88             |
| Вертикальные статусные сцены                       | 720×88             |
| Шесть горизонтальных игровых сцен                  | 480×54             |
| Горизонтальная и вертикальная камера, gameplay ANY | 1080×88            |

В шести игровых сценах колонка шириной 480 px состоит из донатеров, камеры, соцполосы и музыки, расположенных друг под другом. Отступ от края холста не менее 32 px. Все шесть сцен используют одинаковые источники и переход Move; координаты каждой сцены приведены в `gameplay.horizontal`. В горизонтальной камерной сцене источник 1080×88 равномерно увеличен до ширины 1280 px; Move override сопоставляет его с игровым источником 480×54. Вертикальная соцполоса находится непосредственно под камерой. Анимация соцполосы выполняется CSS виджета.

`donors` — полный viewport 1000×134 с равномерным масштабом, `donorVisible` — панель после прозрачных верхних 20 px. Музыка остаётся отдельным event-managed виджетом и при отсутствии события прозрачна. Игровой захват в вертикальной сцене сохраняет crop и bounds.

Перед установкой: свежий read-only аудит, резервная копия, проверка общих источников и отсутствия эфира/записи, затем установка и readback геометрии и порядка слоёв. Установленную конфигурацию этого прохода читать из приватного журнала и бэкапа; координаты дробные, OBS может квантовать bounds. Верхние скругления донатеров применяются через provider CSS `dist/obs-widgets/donors/donationalerts-stream-stats.css` — его нужно вставить в Stream Stats донат-сервиса вручную.

После обновления проверить отображение в работающем OBS. Сборка экспортов не изменяет коллекции сцен и не запускает эфир.

HTML собираются Vite/singlefile в `dist/artwork/html/scenes`. Для локального
просмотра: `bun run build:artwork`. Редактируемый CSS — obs-scene.css;
изображения OBS находятся в `dist/artwork/scenes/`.
