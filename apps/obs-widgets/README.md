# Ресурсы OBS

Соцполоса, оформление чата Streamlabs, CSS DonationAlerts и звуки. Исходники — src, готовые ресурсы — dist. `npm run build:widgets` собирает отдельные продукты и provider-форматы; исходники и соседние приложения не переписываются.

Output Stats исключён из поддерживаемого проекта как legacy по прямому распоряжению владельца. Его исходники, сборка, артефакт, Storybook и назначение установки удалены. Исторические планы и baseline не являются перечнем поддерживаемых продуктов.

## Автономные HTML

`social-strip/SocialStrip.vue` компилируется официальным Vue SSR. Общий `vuePagePlugin` вставляет готовую разметку/стили до обработки Vite/singlefile. Vue runtime/компилятор в клиентских chunks запрещены. Соцполоса содержит только CSS/SVG и не требует JS; прежний цикл подсветки пяти логотипов — 15 секунд, reduced-motion оставляет все логотипы видимыми. Совместимый `transparent.png` сохраняется побайтово.

`node --test tests/obs-widgets.test.mjs tests/obs-widgets-residual.test.mjs tests/retired-widget-contract.test.mjs` проверяет готовую соцполосу, provider fixtures, текст, размеры, alpha и отсутствие исключённого продукта. Сначала собрать widgets и Storybook. В Storybook — тот же SFC без сетевых подключений. Браузерные fixtures не заменяют Windows 11/OBS CEF и проверку реальных провайдеров.

## Форматы провайдеров

Донатеры с 21.10.2026: постоянный фон на stats-slider/stats-list высотой 114 px внутри источника 1000×134, основной текст до 44 px, подпись до 32 px. В игровых сценах основной текст соответствует примерно 16 px при просмотре в 1080p. Нижний край плашки, радиус поверхности 24 px и вертикальная смена за 0,36 секунды без гашения сохранены. Данные и период ротации остаются у провайдера; CSS сохраняет его v-show. `node --test tests/donors-slide.test.mjs` проверяет оба DOM-режима, длинные имена, подпись и reduced-motion. Установка в существующий источник OBS и сохранение на диск проверены; подробности — соседний Streamer.bot/custom/maintenance/donors-readability-20261021/README.md.

Streamlabs и DonationAlerts получают исходные HTML/JS и готовый CSS из dist. Vue туда не внедряется. Сборка встраивает один Unbounded 400/OFL и только используемые семантические токены; сохраняет имена адаптеров `--cm-*`, placeholders, обработчики событий и задержки анимаций. Чат, alert и донатеры используют светлую поверхность; внешний canvas остаётся прозрачным.

Каталог показывает именно готовые CSS и шаблон Streamlabs через exports `delivery/*`. После правок provider source сначала выполнить `npm run build:widgets`, затем `npm run build:storybook` или `npm run test:ui`. Offline fixtures проверяют формат поставки, но не подтверждают DOM/CSP аккаунта внешнего провайдера.

Чат: ник Unbounded 400 расположен над сообщением Arial, поверхность светлая, внешний canvas прозрачный. Сообщение стримера имеет синий заголовок, упоминание — синюю границу слева. Цвета ников Twitch не заменяют фирменные контрастные пары; декоративных «искр», теней и внешних шрифтов нет. Длинные ники сокращаются, текст переносится без обрезки. Шаблон сохраняет `data-from`, `data-id`, `.badges` и `.message`; контейнер имеет семантику журнала. `streamlabs-chat-design.test.mjs` проверяет ширины 320/390/540/1100, конфликт старой темы и reduced-motion.

При установке чата обновлять **HTML и CSS в самом Streamlabs**, а затем согласованный override OBS. Старый CSS аккаунта нельзя считать заменённым после копирования локального файла: его псевдоэлементы и inline-цвета могут смешиваться с новым оформлением. Существующий размер текста OBS сохранять через `prepareObsChatCss`; задержки/удаление сообщений остаются у провайдера.

## Установка

Соцполоса прикрепляется к верхнему краю: верхние углы прямые, нижние скруглены на 12 px. С 21.10.2026 этот вариант установлен в OBS, включая согласованный CSS override существующего источника. Изменение углов требует обновления локального HTML и override; остальные параметры источника сохраняются.

`npm run sync:local -- --product widgets` показывает назначения, `--apply` обновляет локальные ресурсы с резервными копиями. Публикация CSS в Streamlabs/DonationAlerts выполняется отдельно через интерфейс сервиса. Единственный исходник CSS донатеров — src/donors/donationalerts-stream-stats.css. Сборка не обновляет рабочие источники/настройки OBS и не запускает эфир.
