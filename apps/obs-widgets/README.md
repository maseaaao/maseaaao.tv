# Ресурсы OBS

> Обновление 23.10.2026: актуальные анимации и ограничения описаны в [motion-system.md](../../docs/motion-system.md). Указанные ниже параметры движения и результаты OBS за 21–22 октября являются историей предыдущей версии.

Соцполоса, оформление чата Streamlabs, CSS DonationAlerts. Исходники — src, готовые ресурсы — dist. `bun run build:widgets` собирает отдельные продукты и provider-форматы; исходники и соседние приложения не переписываются.

Output Stats исключён из поддерживаемого проекта как legacy по прямому распоряжению владельца. Его исходники, сборка, артефакт, Storybook и назначение установки удалены. Исторические планы и baseline не являются перечнем поддерживаемых продуктов.

## Автономные HTML

`src/social-strip/index.html` содержит авторскую разметку; Vite/singlefile встраивает CSS и шрифт без SSR и шаблонизатора. Соцполоса содержит только CSS/SVG и не требует JS. Раз в 30 секунд по пяти логотипам проходит мягкая волна продолжительностью 1,56 секунды: подъём до 2 px, масштаб до 1,06, opacity от 0,82 до 1. Ник, разделитель и плашка неподвижны; между проходами значки стоят спокойно. Reduced-motion задаёт `--social-animation: none` и `--social-rest-opacity: 1`; все логотипы остаются видимыми. В эфирном источнике OBS явно установлены `--social-animation: social-wave !important` и `--social-rest-opacity: .82 !important`, как согласованный выбор движения для стрима.

`bun test tests/obs-widgets.test.mjs tests/obs-widgets-residual.test.mjs tests/retired-widget-contract.test.mjs` проверяет готовую соцполосу, provider fixtures, текст, размеры, alpha и отсутствие исключённого продукта. Сначала собрать widgets и Storybook. Проверяется готовый автономный HTML без сетевых подключений. Браузерные fixtures не заменяют Windows 11/OBS CEF и проверку реальных провайдеров.

## Форматы провайдеров

Донатеры с 21.10.2026: постоянный фон на stats-slider/stats-list высотой 114 px внутри источника 1000×134, основной текст до 44 px, подпись до 32 px. В игровых сценах основной текст соответствует примерно 16 px при просмотре в 1080p. Нижний край плашки и радиус поверхности 24 px сохранены. Согласованная анимация — вертикальный перекат за 520 мс: поворот текста до 16° у краёв, небольшое сжатие и затухающая остановка без отскока; в покое исходный размер и плоский текст. Фон неподвижен, opacity текста равна 1. Данные и период ротации остаются у провайдера; CSS сохраняет его v-show и transitionend. `bun test --timeout=120000 tests/donors-slide.test.mjs` проверяет оба DOM-режима, длинные имена, подпись, reduced-motion и явное включение движения для эфира. По умолчанию `--cm-roll-duration` равна 0,52 с, при reduced-motion — 0,001 с. В текущем OBS системная настройка уменьшенного движения включена; по выбору владельца в CSS override источника добавлена `:root { --cm-roll-duration: .52s !important; }`, аналогично `motion=1` у музыки. Локальные экспорты содержат базовый CSS, явное включение принадлежит настройкам OBS. Четыре теста, три естественные смены провайдера и 580 кадров OBS CEF проверены; настройка сохранена на диск. Подробности — соседний Streamer.bot/custom/maintenance/donors-roll-20261021/README.md; предыдущая правка читаемости — donors-readability-20261021/README.md.

Streamlabs и DonationAlerts получают исходные HTML/JS и готовый CSS из dist. Vue туда не внедряется. Сборка встраивает один Unbounded Variable WOFF2/OFL и только используемые семантические токены; сохраняет имена адаптеров `--cm-*`, placeholders, обработчики событий и задержки анимаций. Чат, alert и донатеры используют светлую поверхность; внешний canvas остаётся прозрачным.

Каталог показывает именно готовые CSS и шаблон Streamlabs через exports
`delivery/*`. После правок provider source сначала выполнить `bun run build:widgets`.
Поставка — только записанные CSS: DOM/CSP аккаунта внешний провайдер меняет сам.

Чат: ник Unbounded 400 расположен над сообщением Arial, поверхность светлая, внешний canvas прозрачный. Сообщение стримера имеет синий заголовок, упоминание — синюю границу слева. Цвета ников Twitch не заменяют фирменные контрастные пары; декоративных «искр», теней и внешних шрифтов нет. Длинные ники сокращаются, текст переносится без обрезки. Шаблон сохраняет `data-from`, `data-id`, `.badges` и `.message`; контейнер имеет семантику журнала. `streamlabs-chat-design.test.mjs` проверяет ширины 320/390/540/1100, конфликт старой темы и reduced-motion.

При установке чата обновлять **HTML и CSS в самом Streamlabs**, а затем согласованный override OBS. Старый CSS аккаунта нельзя считать заменённым после копирования локального файла: его псевдоэлементы и inline-цвета могут смешиваться с новым оформлением. Существующий размер текста OBS сохранять через `prepareObsChatCss`; задержки/удаление сообщений остаются у провайдера.

## Установка

Соцполоса прикрепляется к верхнему краю: верхние углы прямые, нижние скруглены на 12 px. С 21.10.2026 этот вариант установлен в OBS, включая согласованный CSS override существующего источника. Изменение углов требует обновления локального HTML и override; остальные параметры источника сохраняются.

С 21.10.2026 соцполоса видна по одному разу во всех 12 горизонтальных сценах (включая две базовые) и 5 вертикальных. В горизонтали используется положение x=830, y=0, размер 900×53,33 на холсте 2560×1440. Источник добавлен в `📁ИГРА` и `📁БАЗА`, поэтому игровые сцены и старт/пауза/конец наследуют его; прежние прямые размещения в трёх последних сценах отключены с сохранением ID. `🎥CAMERA` и вертикальные сцены сохраняют свои прежние прямые размещения. Один существующий браузерный источник 1080×64/30 FPS переиспользуется; дополнительных inputs не создано. HTML обновлён, анимация проверена на 272 кадрах реального OBS CEF, настройки и размещения сохранены коллекцией. Подробности и резервная копия — Streamer.bot/custom/maintenance/social-wave-20261021/README.md.

`bun run sync:local --product widgets` показывает назначения, `--apply` обновляет локальные ресурсы с резервными копиями. Публикация CSS в Streamlabs/DonationAlerts выполняется отдельно через интерфейс сервиса. Единственный исходник CSS донатеров — src/donors/donationalerts-stream-stats.css. Сборка не обновляет рабочие источники/настройки OBS и не запускает эфир.
