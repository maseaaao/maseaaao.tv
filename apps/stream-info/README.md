# Stream Info

Автономный русский док OBS: общее название, шаблоны, категории и теги для
Twitch и YouTube. Соединяется с WebSocket Streamer.bot; OAuth остаётся в
Streamer.bot.

1. Из корня выполните `bun run build:stream-info`.
2. Подключите `dist/stream-info/change-info-streamer-bot.ru.html` из корня репозитория как док OBS.
3. Включите WebSocket Streamer.bot и укажите подключение в настройках дока.
   Импортируйте `dist/stream-info/streamerbot-import.txt`, если API отсутствует или изменился C#;
   Action `STREAM INFO | API` должен быть включён. Сохраняйте существующие ID.

Для просмотра без соединения добавьте `?demo=1`. Шрифт и стили встроены.
Пароль сохраняется только с флажком «Запомнить пароль». Черновик шаблонов живёт
в sessionStorage вкладки; сохранённые шаблоны — в постоянных переменных Streamer.bot.

## Как устроен редактор

- «Общее название» подставляется в шаблон каждого канала. Название можно
  переключить на полное отдельно для Twitch и YouTube.
- Twitch: поиск категории, название до 140 символов.
- YouTube: выбор категории из стандартного списка, название до 100 символов
  без `<` и `>`. Streamer.bot умеет менять данные YouTube только у запущенной
  трансляции; до эфира карточка показывает предупреждение и остаётся только для
  чтения.
- Теги общие для Twitch и YouTube: до 10 тегов, до 25 символов, без пробелов.
  При сохранении один набор уходит в обе платформы.
- В начале YouTube-эфира действие автоматически ставит категорию `Видеоигры` и
  копирует теги из Twitch.
- Общая кнопка «Применить изменения» сохраняет общий подзаголовок, оба шаблона и
  изменения доступных платформ. Ошибка одной платформы не отменяет изменения
  другой; черновики остаются.
- В шаблоне нужен ровно один `$s` — общее название. Токен `$g` необязателен и
  подставляет текущую категорию Twitch; если категория не выбрана, `$g` исчезает.
  Пример YouTube-шаблона: `🔴 $g | $s| !tg !yt !tw !donate`.

Шаблоны хранятся в постоянных переменных:

| Переменная                      | Назначение     |
| ------------------------------- | -------------- |
| `stream_info.template.subtitle` | Общее название |
| `stream_info.template.twitch`   | Шаблон Twitch  |
| `stream_info.template.youtube`  | Шаблон YouTube |

## Автозапуск YouTube

В импортируемом Action уже включён триггер `YouTube → Broadcast → Started`.
После начала YouTube-эфира он ждёт до 15 секунд, ставит категорию `Видеоигры`
и копирует текущие теги Twitch в YouTube. Название автоматически не меняется.
Если теги Twitch пусты, категория всё равно выставляется.

## Пресеты

Для игрового пресета создайте `PRESET | Название игры` в группе `STREAM INFO`:
задайте persistent globals и вызовите API с `command=applyPreset`.

| Переменная                               | Платформа                       |
| ---------------------------------------- | ------------------------------- |
| `stream_info.preset.twitchCategoryId`    | Twitch: ID категории            |
| `stream_info.preset.youtubeCategoryName` | YouTube: название категории     |
| `stream_info.preset.tagsJson`            | Общие теги обеих платформ       |
| `stream_info.preset.twitchTagsJson`      | Старый набор Twitch (fallback)  |
| `stream_info.preset.youtubeTagsJson`     | Старый набор YouTube (fallback) |

Общие теги имеют приоритет. Пустые категория и теги не меняют текущие значения.
YouTube применяется только во время эфира, иначе пресет для него пропускается.

## Разработка

`src/render.ts` создаёт DOM, `src/controller.ts` управляет состоянием и транспортом.
Каждый `initDock()` возвращает независимый док с `dispose()` для освобождения ресурсов.
Кеш API — 5 секунд со сбросом после записи. `API_VERSION` и C# `ApiVersion` должны
совпадать.

Из корня: `bun run test:stream-info` (только JS/TS, без .NET).
C#-тесты запускайте отдельно через `bun run test:csharp` (нужен .NET SDK 8).
Они не входят в общий `bun run test` и обязательные проверки CI.

[Подключение](../../docs/local-installation.md).

## Цель на фолловеров

`streamerbot/creator-goal.cs` — отдельное действие Streamer.bot `Creator Goal`
(Execute Code). Оно читает активную цель через Creator Goals API и пишет её
в persistent global `twitchGoal`:

```json
{ "type": "follower", "current": 18, "target": 20, "description": "…", "updated": 1760000000 }
```

1. Импортируйте C# как действие `Creator Goal` (сохраняйте существующие ID).
2. Нужен scope `channel:read:goals` у broadcaster-токена. Если Helix отвечает
   401 — переподключите Twitch в Streamer.bot.
3. Виджет соцполосы сам вызывает действие по WebSocket при загрузке и раз в
   30 секунд, затем читает `twitchGoal` через `GetGlobals`.

Нет активной цели — global пустой, виджеты скрывают счётчик. Цель и её текущее
значение берутся только из Twitch; в виджете ничего не хардкодится.
