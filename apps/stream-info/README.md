# Stream Info для Streamer.bot

Автономный русский док OBS для Twitch: название, категория, теги, шаблон и игровые пресеты. Подключается к локальному WebSocket Streamer.bot; OAuth-данные остаются внутри Streamer.bot.

Собрать из корня репозитория: `npm run build:stream-info`. Готовый файл — `dist/change-info-streamer-bot.ru.html` в этом приложении. Подключить его через OBS Dock. Для просмотра без соединения добавить `?demo=1` (демонстрацию включает само наличие параметра `demo`). Vue, шрифт и стили встроены в HTML; соседние файлы и CDN не нужны.

Включить WebSocket Streamer.bot, импортировать streamerbot-import.txt при изменении C# и проверить включённый STREAM INFO | API. Имена и ID API сохраняются. Параметры подключения хранятся в localStorage; пароль — только с флажком «Запомнить пароль». Несохранённый шаблон восстанавливается из sessionStorage этой вкладки; восстановление после закрытия вкладки не гарантируется. Остальные несохранённые поля живут в текущем экземпляре дока. Сохранённые шаблоны — в постоянных переменных Streamer.bot.

Для пресета создать Action PRESET | Название игры в группе STREAM INFO. Он задаёт persistent globals `stream_info.template.twitch`, `stream_info.template.subtitle`, `stream_info.preset.twitchCategoryId`, `stream_info.preset.twitchTagsJson`, затем вызывает API с command=applyPreset. Пустые категория/теги не меняют соответствующие поля.

Проверки из корня: `npm run check:stream-info`, `npm run test:stream-info`. Кеш состояния — 5 секунд со сбросом после записи. Поиск категорий ранжирует результаты, сохраняет выбор по ID и отличает ошибку от пустой выдачи.

UI реализован настоящими Vue SFC: `src/main.ts` только монтирует `App.vue`; `src/components/` содержит локальные редакторы, поиск категорий и диалог; `src/composables/useStreamInfo.ts` владеет реактивным состоянием и транспортом. Общие элементы импортируются из `@maseaaao/ui` через workspace exports. Шаблоны компилируются Vite заранее, runtime-компилятор не используется. `AppIcon.vue` создаёт static SVG VNode только из доверенных bundled SVG; сетевые данные выводятся текстом, `v-html` в приложении нет.

Каталог Storybook использует публичные exports `change-info-streamer-bot/App.vue` и `change-info-streamer-bot/ui.css`. Для подставного экрана задан `demo=true`: подключение к Streamer.bot запрещено и после сохранения настроек. Стили экрана добавляются на время монтирования story, а не глобальным импортом для всех stories.

Проверки готового файла: `node --test tests/stream-info-delivery.test.mjs tests/stream-info-transport.test.mjs` из корня после сборки. Они открывают только готовый HTML через `file://`: автономные ресурсы, реальные начертания шрифта, ширины 320/390/540/1280, увеличенный текст, reduced-motion, focus trap/возврат фокуса, протокол настоящего клиента с подставным WebSocket и повторное открытие страницы по тому же пути. Повторное открытие страницы в одном browser context не доказывает сохранение после перезапуска браузера/OBS. Полный `test:stream-info` дополнительно требует .NET 8; отдельно доступна Vue-часть: `npm exec --workspace apps/stream-info -- vitest run`.

Каждое монтирование создаёт независимое подключение. При размонтировании удаляются polling/visibility listener, debounce, отложенные эффекты и pending-запросы, закрывается клиент; устаревшие ответы не меняют UI. Подключение, шаблоны и метаданные сохраняются отдельно. Ошибка/частичный успех оставляют черновики, текст ещё не добавленного тега не отправляется автоматически.

Светлый док с синей внешней рамкой рассчитан в том числе на ширины 320/390/540 px. Шрифты — встроенный Unbounded 400 и системный Arial. Автоматические браузерные проверки не заменяют приёмку в Windows/OBS CEF. [Установка](../../docs/local-installation.md), [выпуски](../../docs/releasing.md), [лицензия](LICENSE).
