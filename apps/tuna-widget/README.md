# Tuna Widget

Версия 1.1.0, автономный музыкальный виджет с прозрачной внешней областью и светлой поверхностью. Unbounded 400 и стили встроены, основной текст — Arial. Готовый файл — `dist/obs-tuna-widget.html`; дополнительных UI-файлов или сервера интерфейса не нужно.

`npm run build:tuna` из корня использует общий `buildVuePages`: `src/TunaFrame.vue` рендерится официальным Vue SSR, затем Vite/singlefile встраивает CSS/JS/шрифт/лицензию. `render.mjs` и `build.mjs` работают только при сборке. Клиентский Vue runtime не добавляется. `src/main.js` — прежний контроллер; изменено только место подключения CSS, логика переключения треков сохранена; добавлена необязательная диагностика отказов HTTP/обложек. Бюджеты: HTML ≤200000 байт, JS ≤12000 байт без gzip.

Порт локального сервера Tuna по умолчанию 1608. Сохранены все URL-параметры `poll`, `start`, `show`, `anim`, `idle`, `art`, `swap`, `retry`, `tries`, `timeout`, `fail`, `img`, `ui`, `port`; дополнительный `debug=1` выводит причины ошибок локального Tuna/обложек только в консоль и не меняет оформление OBS; первые/сменённые треки, пауза, порог неудачных опросов, задержки/ретраи обложки, cache-busting локального URL и защита от устаревших загрузок принадлежат прежнему контроллеру. Внешний Tuna API и обложка — функциональные зависимости, не зависимости UI.

`opaque=1` сохраняет режим общего слота с донатерами; без дополнительных параметров это прежний непрозрачный выезд целой карточки снизу. `anim` задаёт длительность движения, `idle` — видимую долю (0 скрывает, 1 оставляет полностью открытым). Без opaque сохраняется прежнее растворение и смысл idle как прозрачности. Радиус поверхности — 24 px. Reduced-motion отключает движение, если владелец явно не добавил `motion=1` для эфирного оверлея.

`opaque=1&reveal=soft` включает послойное появление из прозрачного пространства: подложка мягко проявляется и расправляется, обложка и текст появляются после её перехода в непрозрачное состояние. При уходе сначала исчезает содержимое, затем подложка. Небольшие смещение/масштаб используют критически затухающий отклик без отскока; незавершённый переход перенаправляется из текущего положения. Анимация исполняется Web Animations API без постоянного JS-цикла и без размытия. Старые режимы остаются совместимыми. В OBS установлен `opaque=1&reveal=soft&motion=1&anim=420`; интервалы показа 60000/5000 мс, idle=0 и геометрия сохранены. Реальные проверки OBS CEF и видеопревью — Streamer.bot/custom/maintenance/music-soft-20261021/README.md.

Проверка: `node --test tests/tuna-widget.test.mjs`. Готовый файл открывается через `file://` в пустой папке с подставными ответами; проверяются параметры, воспроизведение/пауза, лимит ретраев и восстановление обложки, светлая поверхность, 320/390/540/1000 px, встроенный шрифт и alpha углов. Storybook показывает тот же `TunaFrame` на статических данных без запуска контроллера. Windows 11/OBS CEF и реальные настройки Tuna проверяются отдельно; сборка не обновляет рабочий источник.

Обновление существующего источника: `npm run sync:local -- --product tuna`, затем при необходимости `--apply`. См. ../../docs/local-installation.md. Выпуск: tuna-widget-v1.1.0; новый тег не создаётся при миграции дизайна.
