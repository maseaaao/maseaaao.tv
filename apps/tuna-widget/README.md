# Tuna Widget

Версия 1.1.0, отдельный светлый виджет. Исходники — src/index.html, src/styles.css и src/main.js; `npm run build:tuna` из корня генерирует dist/obs-tuna-widget.html со встроенными шрифтами и лицензиями. Изменения не устанавливаются автоматически.

Порт локального сервера Tuna по умолчанию 1608. Параметры URL и тайминги сохранены из установленного виджета. Проверка: `node --test tests/tuna-widget.test.mjs` (подставные данные, реальное воспроизведение не запускается).

Обновление существующего источника: `npm run sync:local -- --product tuna`, затем при необходимости `--apply`. См. ../../docs/local-installation.md. Выпуск: tuna-widget-v1.1.0; тег при переносе не создан.
