# Tuna Widget

Автономный музыкальный виджет OBS. Требует работающий локальный сервер Tuna
(по умолчанию `http://localhost:1608/`); шрифт и стили встроены в HTML.

Из корня: `bun run build:tuna`. Подключите
`dist/tuna-widget/obs-tuna-widget.html` из корня репозитория как браузерный источник OBS.

Для автономного предпросмотра без обращений к Tuna добавьте `?demo=1`.
Для реального подключения откройте тот же URL без этого параметра.
В общем dev-запускателе предпросмотр включён автоматически.

## URL-параметры

| Параметры                         | Назначение                                                            |
| --------------------------------- | --------------------------------------------------------------------- |
| `port`, `poll`, `timeout`, `fail` | Порт, опрос, таймаут и порог ошибок                                   |
| `start`, `show`, `anim`, `idle`   | Время показа, длительность перехода и состояние покоя                 |
| `opaque=1`                        | Непрозрачная карточка; `idle` задаёт видимую долю вместо прозрачности |
| `opaque=1&reveal=soft`            | Послойное появление подложки, обложки и текста                        |
| `motion=1`                        | Явно включает движение при системном reduced-motion                   |
| `art`, `swap`, `retry`, `tries`   | Задержка обложки, переход и повторные попытки                         |
| `img`, `ui`                       | Масштаб обложки и интерфейса                                          |
| `debug=1`                         | Диагностика запросов и обложек в консоли                              |

Время задаётся в миллисекундах. Значения по умолчанию и допустимые диапазоны —
в `src/main.ts`. При обновлении сохраняйте URL-параметры существующего источника.
