# UI Gallery

Локальная витрина переиспользуемого UI/UX.
Настоящие стили `@maseaaao/design` и `@maseaaao/ui`: токены, типографика,
размеры, движение, кнопки, поля и статусы со всеми общими состояниями.
Поиск по названию и CSS-классу; у компонентов раскрывается готовая разметка
с импортами и кнопкой копирования. Примеры интерактивны, но не вызывают сервисы.

Из корня:

```bash
bun run dev:ui
bun run build:ui
```

Dev-сервер показывает адрес в терминале. Сборка — автономный каталог
`dist/ui-gallery/`: `index.html` открывается прямо с диска, без сети и сервера.
Переносите каталог целиком: изображения находятся рядом, в `artwork/`.
Включает локальный шрифт и его OFL. Публикуется по `/ui/` при общем
деплое Cloudflare, не входит в Windows-комплект. `build:all` включает галерею; `build:apps` остаётся
сборкой пользовательских продуктов.

Радиусы показаны на одинаковых плашках с квадратным пунктирным контуром,
значением токена и фактическим радиусом в пикселях.

Раздел Motion показывает запускаемые примеры всех таймингов и easing-кривых
из общих токенов. Можно воспроизвести их вместе, замедлить до 0,25× или
посмотреть конечные состояния без движения. Системный `prefers-reduced-motion`
учитывается автоматически. Анимации не запускаются сами и не зациклены.

Изображения разделены на вкладки: логотипы, сцены, баннеры, панели Twitch,
обои и бренд. Превью сохраняют пропорции и прозрачность; по нажатию открывается
полное изображение с возможностью скачать оригинал. Подписи показывают путь,
размеры в пикселях после загрузки и вес файла.

Галерея читает готовые изображения из `dist/artwork/`, а также утверждённые
оригинал логотипа и SVG-маску из `artwork/`. Ничего не рендерит и не изменяет:
при сборке файлы копируются байт-в-байт в собственный каталог галереи.
Если экспортов ещё нет, вкладка объясняет, что нужно выполнить
`bun run render:all` в согласованной Linux-среде. После обновления экспортов
перезапустите dev-сервер или повторите `bun run build:ui`.

Примеры находятся в `src/index.html`; добавляйте секцию с `data-example`,
заголовком и `.example-preview` — поиск и разметка подключаются автоматически.
Токены читаются из публичного `@maseaaao/design/tokens.css`, не дублируются.
Стили самой витрины в `src/styles.css` не являются API общих компонентов.
Паттерны, пока живущие только в приложениях, не выдаются за общий пакет.
