Человекочитаемая документация ресурсов сайта для людей и агентов.

Инструменты стрима и версии

Обзор

maseaaao.tv — статический сайт-хаб стримера maseaaao: стримы, клипы, соцсети и контакты. Публичных серверных API нет — все ресурсы отдаются как статические файлы по HTTPS.

Каталог для агентов (RFC 9727)

GET /.well-known/api-catalog — каталог ресурсов в формате Linkset JSON (RFC 9264). Главная страница ссылается на него через HTTP-заголовок Link с отношением rel="api-catalog".

Machine-readable ресурсы

/manifest.webmanifest — web app манифест.

/sitemap.xml — карта сайта.

/robots.txt — правила для краулеров.

Страницы

/ — главная: Twitch, Telegram, YouTube, Instagram, TikTok и поддержка.

/check.html — Stream Checker: инструмент проверки встраиваемых плееров.

/docs.html — эта страница.

Заголовки обнаружения (RFC 8288 / RFC 9727) отдаются на главной: api-catalog и describedby.
