# Интеграции

- [Companion](companion/README.md): SystemMicrophone, VoiceStream и запускатель Windows.
- [DonationAlerts](streamerbot/donationalerts/README.md): авторизация, слушатель и сообщения в чат.
- `streamerbot/chat-sound/`: звук чата и `notif.mp3`.
- `streamerbot/obs-health/`: проверка OBS и `health-warning.mp3`.

C# исполняется внутри Actions Streamer.bot. Изменение исходника не обновляет
установленный Action. [Подключение и проверка](../docs/local-installation.md).
