# Интеграции

- [DonationAlerts](streamerbot/donationalerts/README.md): авторизация, слушатель,
  сообщение в чат и кнопка скрытия алертов.
- [DroidCam](streamerbot/droidcam/README.md): включение/выключение камеры,
  анимация сцен и арт категории.
- `streamerbot/chat-sound/`: звук чата и `notif.mp3`.
- `streamerbot/stream-deck/`: действия для кнопок Stream Deck.
- `streamerbot/vod/`: жизненный цикл YouTube-записи и ссылка на удаление.

C# исполняется внутри Actions Streamer.bot. Изменение исходника не обновляет
установленный Action. [Подключение и проверка](../docs/local-installation.md).
