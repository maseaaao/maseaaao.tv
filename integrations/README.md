# Интеграции

streamerbot: исходники DonationAlerts, Яндекс Музыки, OBS Health и игровых пресетов. companion: System Microphone 1.2.1 и VoiceStream 1.0.22, общий помощник процесса. Текущие установленные копии остаются вне репозитория.

Не запускать интеграции ради проверки переноса. Команды сборки в корневом README создают пакеты, не устанавливая их. Новому DonationAlerts требуется приватная глобальная переменная daClientSecret; реальный секрет в исходниках отсутствует. Порядок подключения — docs/local-installation.md от корня.
