# Изменения VoiceStream

## 1.1.1

- Одинаковые UUID Actions запуска и остановки отклоняются независимо от регистра. Сохранённые ID не меняются.
- Добавлены регрессионные проверки остановки runtime, отсутствия запусков audio/OBS/Discord и восстановления после исправления конфигурации.
- Переведены оставшиеся подписи feedback и пресетов, включая кнопку «СБРОС»; ID и горячие клавиши сохранены.
