# DroidCam: одна кнопка на все сцены

`DroidCamToggle.cs` устанавливается вместе с `obs-health/CompanionEndpoint.cs` в один
Execute C# Code. Companion вызывает его через HTTP-соединение Streamer.bot:
`POST /DoAction`, имя `OBS | DroidCam | Toggle` (кнопка `1/2/2` на странице «ГЛАВНАЯ»).

Нажатие выключает камеру: вход DroidCam деактивируется (`activated=false`), затем
скрываются все его элементы сцен и все элементы клона `КАМЕРА [clone]` — на основном
канвасе и на Aitum Vertical. Повторное нажатие включает: сначала элементы показываются,
потом вход активируется (скрытый вход не запускает видео даже после активации).

Источники определяются по UUID в исходнике; при переносе в другую коллекцию их
необходимо проверить. Каждая запись OBS проверяется чтением, поэтому молча не
применённая запись возвращает ошибку. Сцены перечисляются через `GetCanvasList` и
`GetSceneList` с UUID канваса; на сборках без поддержки канвасов используется обычный
`GetSceneList` (вертикальный канвас тогда не затрагивается).

В Companion нужны постоянные custom variables `droidcam_state` и `droidcam_label`.
Подпись кнопки — `$(custom:droidcam_label)`, цвет — выражение по `droidcam_state`
(`1` — включена). `Init` только читает OBS и синхронизирует подпись; ручные изменения
в свойствах источника между нажатиями автоматически не отслеживаются.

`TestDroidCamToggle.cs` проверяет выключение и включение (включая порядок операций),
read-only `Init`, молча не применённые записи, ошибку OBS, запасной путь без
`GetCanvasList` и камеру внутри группы — на подставных OBS/HTTP-обработчиках.
