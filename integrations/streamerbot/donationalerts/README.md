# DonationAlerts → чат Streamer.bot

Интеграция принимает донаты и передаёт их в обработчики Actions.
`DonationChat.cs` формирует сообщение для Twitch и для отслеживаемой live-трансляции
YouTube с доступным чатом. Голосовой донат обозначается текстом; длинные сообщения сокращаются.

## Настройка

Задайте приватную постоянную глобальную переменную `daClientSecret` из конфигурации
приложения DonationAlerts. `daClientId` необязательна. Без секрета инициализация
останавливается. Не включайте секрет в исходники или публичные экспорты.

C# устанавливается в Execute Code существующих Actions с сохранением ID:

| Action / модуль                                         | Исходник и назначение                                           |
| ------------------------------------------------------- | --------------------------------------------------------------- |
| `-- DonationAlerts Code` / `DonationAlerts Integration` | `DonationAlertsIntegration.cs`: подключение и обработка событий |
| `-- DonationAlerts Authorization`                       | `DonationAlertsAuthorization.cs`: OAuth через браузер           |
| `-- DonationAlerts Background Watcher`                  | `DonationAlertsWatcher.cs`: запуск слушателя                    |
| `DonationHandler_After`                                 | `DonationChat.cs`: отправка сообщения                           |

`WebSocketMessages.cs` — общий код чтения WebSocket, учитывайте его при обновлении
C#. Watcher вызывается при старте Streamer.bot; используйте отдельную блокирующую
очередь. Для авторизации запустите `-- DonationAlerts Authorization` и подтвердите
доступ в браузере в течение пяти минут. При истечении авторизации повторите подключение.

Слушатель восстанавливает соединение с задержкой до 30 секунд и отбрасывает
повторные донаты по ID; дедупликация не переживает перезапуск Streamer.bot.
Файлы исходников не подтверждают, какая версия загружена в приложение.
Обновляйте через штатные средства, сохранив экспорт; не редактируйте живую базу.

`TestMessages.cs` и `TestSocketService.cs` используют подставные сервисы.
Проверка компиляции описана в инструкции подключения из исходников репозитория;
она не доказывает доставку настоящего доната. Не отправляйте сообщения ради проверки.
