# Работа с maseaaao.tv

Общаться по-русски. Начинать с README.md и документации затронутой подсистемы.
- `apps/website/src` — страницы Vue SFC, предварительно отрендеренные официальным Vue SSR в готовый HTML; клиентский Vue runtime сайту не нужен; `apps/website/public` содержит неизменяемые публичные ресурсы. После изменения выполнять `pnpm run build:website`; корневой `dist` — отслеживаемый результат для Cloudflare.
- `apps/stream-info` — полный продукт с C#, импортом и русским интерфейсом. Проверки из корня: `check:stream-info`, `test:stream-info`, `build:stream-info`.
- `apps/tuna-widget` — автономный виджет; сохранять тайминги, ретраи, ограничение попыток и параметры URL. Проверки: `build:tuna`, `node --test tests/tuna-widget.test.mjs`.
- `packages/design` — единственный источник общей палитры и шрифтов; `packages/ui` — подтверждённые общие UI-примитивы; `packages/build-config` — только конфигурации сборки. Интерфейсы только светлые.
- `artwork` — исходники и экспорты оформления, `tooling/artwork` — генераторы. Менять источник перед экспортом; утверждённые аватар и QR сохранять.
- OBS использует изображения напрямую из `artwork`; корневые совместимые `src/assets` удалены. Все браузерные продукты используют только Unbounded и системный Arial.
- `integrations` — код интеграций, а не живые конфигурации приложений.

Использовать pnpm workspaces и единственный корневой lockfile, `pnpm install --frozen-lockfile`, Node.js из `.node-version` (22.23.3), pnpm 12.15.0 из `packageManager`, .NET 8 для Stream Info. Не коммитить секреты, рабочие базы, экспорты аккаунтов, логи, node_modules и снимки диагностики. Сохранять лицензии.

Не запускать apply/configure/install ради исследования. Для проверки миграции не выполнять Actions, не менять эфир, сцены, звук, метаданные, воспроизведение и сообщения; использовать подставные обработчики. Кеш Stream Info — 5 секунд со сбросом после записи, менять только по задаче.

`sync:local` по умолчанию показывает план. `--apply` явно обновляет разрешённые файлы с резервными копиями. Импорт C# в Streamer.bot и установка модуля Companion — отдельные операции. Сборка не доказывает обновление рабочего приложения. Не редактировать живые данные на диске при работающем владельце.

OBS-виджеты: исходники `apps/obs-widgets/src`, результаты `apps/obs-widgets/dist`, сборка `pnpm run build:widgets`. Artwork: `pnpm run build:artwork` готовит автономные HTML в `.build-cache/artwork`; генераторы не переписывают source HTML.

Для общего дизайна проверить сайт и Stream Info; для lockfile — все основные проверки. Браузер: `browser:install` или `CHROME_BIN`. Проверять ширины 320/390/540, клавиатуру, контраст, переполнение и локальные ресурсы. Запускать только затронутые генераторы; `full` — при явной необходимости.

Перед коммитом выполнить `pnpm run check` (Biome, проверки политики исходников, типы и предметные проверки), соответствующие тесты/сборки и `git diff --check`. CI не коммитит результаты. Продукты выпускаются независимо, внутренние пакеты не публикуются в npm. Без поручения пользователя не публиковать сайт и релизы. В отчёте указывать свежие проверки и ограничения.

Все браузерные сборки читают source и пишут только свой output. Не возвращать base64 шрифта в исходники. Использовать workspace exports вместо относительных путей в другой пакет. Для CSS провайдеров применять только нужные токены и font-face; placeholders Streamlabs восстанавливаются после PostCSS. Не форматировать и не линтить сгенерированные экспорты как исходники.

Граф задач — Turbo: продукт владеет build/check, внутренние зависимости только `workspace:*`. `check:source` не требует dist; `check:repository`/`check:artifacts` проверяют результаты отдельно. Кеш только `.build-cache/turbo` данного дерева, без remote cache; тесты/растры/упаковка и live sync не кешируются. Браузерные tests/*.test.mjs выполняются последовательно: часть пересобирает общий dist. Подробнее — docs/build-toolchain.md.

Качество исходников: единый `biome.json`, закреплённый Biome, `pnpm run check:fix` для безопасных исправлений. Не включать все правила без разбора и не подавлять замечания целыми каталогами. GritQL в `tooling/biome` сохраняет запрет приведений типов и сырых цветов в Vue. Проверки типов и HTML-контрактов не заменяются линтером. Подробности и точечные исключения — `docs/biome.md`.

Разработка, обслуживание исходников и все CI jobs — Linux/WSL2. Windows runtime Streamer.bot/Companion/OBS, запускатели и PowerShell медиасессии сохранять: они используются непосредственно в Windows. Companion helpers собираются .NET SDK 8 с NuGet reference assemblies net481; packages.lock.json обязателен, CI использует locked restore. Не возвращать Windows runner, системный csc.exe и патч Storybook. Инструкция — docs/linux-development.md.
