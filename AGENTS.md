# Работа с maseaaao.tv

Общаться по-русски. Начинать с README.md и документации затронутой подсистемы.

- `apps/website/public` — редактируемый статический сайт без фреймворка. После изменения выполнять `npm run build:website`; корневой `dist` — отслеживаемый результат для Cloudflare.
- `apps/stream-info` — полный продукт с C#, импортом и четырьмя локализациями. Проверки из корня: `check:stream-info`, `test:stream-info`, `build:stream-info`.
- `apps/tuna-widget` — автономный виджет; сохранять тайминги, ретраи, ограничение попыток и параметры URL. Проверки: `build:tuna`, `node --test tests/tuna-widget.test.mjs`.
- `packages/design` — единственный источник общей палитры и шрифтов. Интерфейсы только светлые. Редактор палитр может показывать образцы генерируемых цветов.
- `artwork` — исходники и экспорты оформления, `tooling/artwork` — генераторы. Менять источник перед экспортом; утверждённые аватар и QR сохранять.
- Корневые `src` и `assets` — игнорируемые копии для старых путей OBS. Не использовать их как исходники.
- `integrations` — код интеграций, а не живые конфигурации приложений.

Использовать npm workspaces и единственный корневой lockfile, `npm ci`, Node.js 22.20+ в ветке 22, .NET 8 для Stream Info. Не коммитить секреты, рабочие базы, экспорты аккаунтов, логи, node_modules и снимки диагностики. Сохранять лицензии.

Не запускать apply/configure/install ради исследования. Для проверки миграции не выполнять Actions, не менять эфир, сцены, звук, метаданные, воспроизведение и сообщения; использовать подставные обработчики. Кеш Stream Info — 5 секунд со сбросом после записи, менять только по задаче.

`sync:local` по умолчанию показывает план. `--apply` явно обновляет разрешённые файлы с резервными копиями. Импорт C# в Streamer.bot и установка модуля Companion — отдельные операции. Сборка не доказывает обновление рабочего приложения. Не редактировать живые данные на диске при работающем владельце.

Для общего дизайна проверить сайт и Stream Info; для lockfile — все основные проверки. Браузер: `browser:install` или `CHROME_BIN`; редактор палитр — `BROWSER_EXECUTABLE_PATH`. Проверять ширины 320/390/540, клавиатуру, контраст, переполнение и локальные ресурсы. Запускать только затронутые генераторы; `full` — при явной необходимости.

Перед коммитом выполнить `npm run check`, соответствующие тесты/сборки и `git diff --check`. CI не коммитит результаты. Продукты выпускаются независимо, внутренние пакеты не публикуются в npm. Без поручения пользователя не публиковать сайт и релизы. В отчёте указывать свежие проверки и ограничения.
