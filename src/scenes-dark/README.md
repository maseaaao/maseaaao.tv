# Тёмные сцены maseaaao

Этот каталог — отдельный тёмный вариант `src/scenes`, без замены основных сцен.

HTML-шаблоны, `tokens.css`, `obs-scene.css`, `layout.json` находятся здесь. Готовые 12 изображений — в `rendered/`, снимки — в `rendered/review/`. Размеры: 2560×1440, 1080×1920 и игровой слой камеры 600×341. Прозрачные зоны сохраняются.

Из корня maseaaao.tv: `npm run render:scenes:dark`. Для установленного Chrome задать `CHROME_BIN`. Генератор — `scripts/build-dark-scenes.mjs`: использует геометрию основных сцен, добавляет отдельную тёмную тему и проверяет неизменность исходного варианта. `rendered/build-report.json` содержит результат свежей сборки.

Палитра продолжает основную айдентику: тёмный #20201e, тёплый светлый #f4f3ec, фирменный синий #1616d9. Unbounded 600 и Arial берутся из общего `dist/assets/brand.css`. Синие поля содержат светлый текст; синий не используется для мелких подписей на тёмном фоне.

Музыкальный виджет использует эти же токены: `OBS/obs-tuna-widget-dark.html`, стиль — `src/widgets/tuna-widget.css`; сборка — `npm run build:tuna:dark`.

Экспорт коллекции и проверки находятся в `OBS/Streamer.bot/custom/obs-dark/`. Создание изображений не импортирует коллекцию и не меняет текущие сцены OBS.
