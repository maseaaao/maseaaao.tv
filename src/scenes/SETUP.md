# MASEAAAO — сцены OBS (Нуар v2)

Статичные фоны в стиле «Нуар»: глубокий чёрный с виньеткой, cine-бары, неоновая hairline, Unbounded 600 для заголовков и никнейма. Вторая строка заголовка — всегда фиолетовая со скосом. Форматы: горизонталь 2560 × 1440, вертикаль 1080 × 1920.

Статусные сцены: крупный заголовок, свободная область живых виджетов и блок «maseaaao.tv» с QR. Огромный фоновый логотип выходит за правый край, непрозрачность 2,5%. На вертикальном игровом/камерном фоне QR не размещён: свободной безопасной области для него нет.

## Файлы и сборка

- `npm run build:noir` — пересобирает шесть статусных сцен (заголовки/никнейм превращаются в векторные контуры Unbounded через opentype.js — шрифты в статичных сценах не нужны и рендер webp совпадает с браузером пиксель в пиксель).
- `npm run render:logo` — логотип/аватары/QR + штамп сцен (`scripts/stamp-scenes.mjs`): QR и векторные подписи вшиваются в HTML.
- `npm run render:scenes` — webp для источников OBS.

Порядок: `build:noir` → `render:logo` → `render:scenes`.

## Добавление в OBS

Источник «Браузер» → «Локальный файл» → HTML (или webp как «Изображение»). Размер источника = размеру формата.

| Сцена | Горизонталь | Вертикаль |
|---|---|---|
| Начало | 01-start.html | 01-start-vertical.html |
| Пауза | 02-pause.html | 02-pause-vertical.html |
| Конец | 99-end.html | 99-end-vertical.html |
| Камера | 04-camera-horizontal.html | 00-blank-vertical.html |
| Игра | без фона — игра на весь экран | 00-blank-vertical.html |

Порядок источников (сверху вниз): живые виджеты → камера → игра → фон.

## Статусные сцены: области живых виджетов

Координаты от верхнего левого угла.

| Источник | Горизонталь: x, y, ширина, высота | Вертикаль: x, y, ширина, высота |
|---|---|---|
| Чат | 1740, 390, 640, 560 | 120, 780, 720, 210 |
| Донат / подписка / музыка | 1740, 1010, 640, 120 | 120, 1009, 720, 116 |
| Топ | 144, 1250, 1100, 64 | 120, 1150, 720, 50 |

Шрифты живых виджетов: Inter (локальные woff2 в `assets/fonts/fonts.css`, кириллица+латиница, 300/400/600); акцентный — Unbounded 600. Цвета: текст #ECECEE, вторичный #9C9CA6 (минимум 400 веса для живого текста), акцент #B79CFF. Панели: rgba(16,16,22,.8), радиус 14, hairline-бордер rgba(183,156,255,.18). Никакого backdrop-filter — в OBS он не блюрит игру под источником.

## Сцена «Камера»

- Горизонталь: камера на весь экран; фон 04-camera-horizontal.html содержит скруглённую панель под чат (1740, 390, 640, 560) и подложку топа (144, 1250, 1100, 64).
- Вертикаль: фон 00-blank-vertical.html; виджеты как у статусных сцен; логотип-источник 960 × 64 при x=60, y=48.

## Сцена «Игра»

- Горизонталь: игра на весь экран, фон не нужен; камеру и виджеты размещаешь сам.
- Вертикаль: логотип 60,48 (960 × 64) → камера 60,144 (960 × 540) → игра 60,708 (960 × 720, согласованное непропорциональное сжатие 16:9) → уведомления/музыка 60,1452 (960 × 192) → топ 60,1668 (960 × 64).

## Логотип, аватар, QR, шрифты

- Мастер: src/logo/logo.png; `npm run render:logo` — webp 1920 × 540, avatar-*, круглые avatar-circle-*/logo-circle.webp, QR (скругление 7%, коррекция H, проверка декодирования 200–777 px), штамп сцен.
- Шрифты: assets/fonts/ — Inter 300/400/600 + Unbounded 600 (woff2, кириллица+латиница) + fonts.css с unicode-range. Источник — Fontsource CDN; лишние (Oswald, JetBrains Mono) не хранятся.

## Музыка (OBS/obs-tuna-widget.html)

Плоская панель rgba(16,16,22,.82), радиус 14, hairline-бордер, точка #B79CFF, Inter. Показ 7 секунд при старте/смене трека, затем полное скрытие. Шрифты подключаются локальным fonts.css — офлайн работает. Область совпадает с «Донат / подписка / музыка»; одновременно с оповещением DonationAlerts не включать.

## Вертикальная безопасная область

Статусы: важный контент x=120–840, y=300–1200 (проектный запас, не официальная маска). В игровых сценах виджеты опущены ниже — при нарезке роликов возможно перекрытие интерфейсом площадок.

## Готовность

Готово: 10 фонов HTML/webp в стиле Нуар, QR с адресом в статусных сценах, свободная область чата, векторные заголовки, локальные шрифты, музыкальный виджет в стиле, пакет и OBS-импорты (OBS/Streamer.bot/design-preview/obs-pack).

Не подключено: живой чат, DonationAlerts, топ, общая очередь событий.

Вертикальный QR расположен внизу по выбранной композиции, вне проектного запаса. Декоративные горизонтальные линии удалены.

Вертикальные фоны: добавлены значок Twitch и подпись twitch / maseaaao векторными контурами. На статусах — x=440, базовая линия y=1850; на общем фоне камеры/игры — по центру, y=1870. Подпись сохраняется при повторной сборке.
