# Независимые выпуски

| Продукт | Версия и тег | Артефакты |
| --- | --- | --- |
| Stream Info | apps/stream-info/package.json, stream-info-vX.Y.Z | четыре HTML и ZIP |
| Tuna | apps/tuna-widget/package.json, tuna-widget-vX.Y.Z | автономный HTML и ZIP |
| Companion | package.json и manifest.json каждого модуля | отдельные tgz, пока ручная установка |
| Сайт | без обязательной версии | корневой dist |

Изменить версию нужного продукта и его CHANGELOG, обновить корневой lockfile. Для общего дизайна проверить потребителей. Внутренние пакеты не публикуются в npm.

После сборки проверить упаковку: `python tooling/package-release.py stream-info-v1.3.3` или `python tooling/package-release.py tuna-widget-v1.0.0`. Результат — игнорируемая .local/release; следующая упаковка заменяет только эту временную папку. ZIP проверяется чтением и сравнением HTML; лицензии включаются.

После проверки коммита создать и отправить тег продукта. Workflow сверит его с версией, выполнит тесты/сборку, создаст черновик выпуска, скачает файлы и сравнит со сборкой. Публиковать черновик после проверки скачанного HTML в OBS. Существующий релиз не перезаписывается; исправление требует новой версии.

Общий releases/latest не определяет последнюю версию отдельного продукта. На страницах инструментов показывать собственную версию и добавлять прямые ссылки только на опубликованные артефакты. Версии 1.3.3 и 1.0.0 подготовлены локально; теги и релизы при миграции не создаются.

Старые выпуски Stream Info остаются в исходном репозитории. Его архивирование, перенос Issues/PR и отключение старых workflow выполняются отдельно после первого проверенного нового выпуска.
