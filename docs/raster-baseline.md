# Пересчёт растрового эталона

Растровые экспорты (`artwork/**/rendered/**`, `dist/*.png|webp|jpg|ico`) отслеживаются в Git и сравниваются побайтово: `check:artifacts` требует, чтобы пересобранные файлы совпали с коммитом.

Эталон привязан к одной операционной системе. Chromium растеризует текст по-разному на Windows и Linux, поэтому одинаковые исходники дают разные байты. Сравнение проходит только внутри той ОС, в которой эталон был принят.

## Текущая каноническая среда

Linux: `ubuntu-latest`, Node из `.node-version`, закреплённая версия Playwright, Python 3.12, системные библиотеки Chromium (`browser:install --with-deps`).

## Когда эталон нужно пересчитать

- Смена ОС канонического runner'а.
- Обновление версии Chromium, Playwright или системных библиотек.
- Изменение шрифта, макета или геометрии сцен.
- Любое изменение, после которого пересобранные растры перестали совпадать с коммитом.

## Что ещё зависит от ОС

Побайтово от ОС зависят не только растры. Вывод PostCSS для OBS-виджетов на Windows и Linux отличается вставкой пустых строк, поэтому собранные `apps/obs-widgets/dist/**/*.css` тоже входят в эталон. Шрифты от ОС не зависят: fonttools, brotli и zopfli закреплены версиями, а инстанцирование переменного шрифта не пересчитывает метку времени.

## Порядок пересчёта

1. Получить артефакты с канонического runner'а: вкладка Actions → Artifacts → `website-and-artwork-preview`.
2. Распаковать архив в отдельный каталог.
3. Применить файлы к отслеживаемым путям:

   ```sh
   node tooling/accept-artifacts.mjs <распакованный каталог>
   ```

   Скрипт сначала находит все отслеживаемые файлы и только потом перезаписывает их: неполный набор оставляет дерево без изменений и завершается ошибкой с перечнем недостающих файлов.

4. Проверить изменения:

   ```sh
   bun run check:artifacts
   git diff --check
   ```

5. Просмотреть `git diff --stat` и закоммитить пересчитанный эталон.

Шрифты от пересчёта не зависят: `fonttools`, `brotli` и `zopfli` закреплены версиями, а инстанцирование переменного шрифта не пересчитывает метку времени. Файл `packages/design/fonts/unbounded-*.woff2` должен совпадать побайтово на любой ОС.

## Чего делать нельзя

- Ослаблять `check:artifacts`: сравнение побайтовое, а не по порогу пикселей.
- Исключать файлы из проверки, чтобы она проходила.
- Подменять эталон молча: пересчёт — отдельный коммит с понятным назначением.
