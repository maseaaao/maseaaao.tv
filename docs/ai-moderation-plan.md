# ИИ-модерация платных сообщений в Streamer.bot

Дата: 11.11.2026. Статус: реализация и живая установка завершены. Хост модерации
работает, ключи OpenCode Go и DeepSeek сохранены в DPAPI, штатный виджет
DonationAlerts заменён локальным browser source `AI | Донат`, вывод включён.
Тестовый донат DonationAlerts прошёл цепочку и был показан; осталось проверить
платный донат в эфире и отсутствие двойного показа на реальной сцене.

`[x]` — выполнено и проверено, `[ ]` — предстоит выполнить.

## Обязательные решения

- [x] Основной провайдер — **OpenCode Go**. Каждый новый запрос сначала направляется в Go.
- [x] **DeepSeek API — только резерв**, когда Go недоступен, исчерпал лимит или не дал корректного ответа. Решение Go «заблокировать» не является поводом для резервного запроса.
- [x] Вся логика работает внутри Streamer.bot: существующая интеграция DonationAlerts, C# Actions, очередь и HTTPS-запросы к ИИ. Внешний сервер и отдельный процесс OpenCode не нужны.
- [x] Штатный виджет DonationAlerts, его звук и TTS отключены заменой URL источника; старый дизайн сохранён локальной вёрсткой на дизайн-системе `maseaaao`.

## Архитектура

```text
DonationAlerts → DonationHandler_After → зашифрованная очередь
                                           → OpenCode Go → allow / block / review
                                              └→ ошибка → DeepSeek API → те же варианты
                                                           └→ ошибка → review
allow → чат Twitch/YouTube
      → browser source AI | Донат: карточка + голосовое сообщение провайдера
      → локальная веб-панель: очередь, review, allow/block/retry, пауза/перезапуск
```

Сетевой слушатель только складывает события в очередь. Проверка и показ идут в
отдельных потоках Action `AI Moderation`; они не блокируют приём событий и другие
Actions. Публичный текст и голос проходят через единое решение модерации.

## Ограничения и следующие шаги

- Реальный платный донат в эфире ещё не проверен; тестовый донат провайдера прошёл, но не заменяет платную приёмку.
- Панель не имеет пароля и доступна только на `127.0.0.1`; не публикуйте порт 7480 наружу.
- При смене коллекции OBS нужно снова заменить URL/имя источника и проверить scene item UUID; старый `DonationAlertsToggle` использует UUID.
- `System.Speech` больше не используется для донатов; голосовой файл воспроизводит browser source. При отсутствии `daAudio` голосовой донат остаётся в review и не выпускается.
- Если `queue.dpapi` повреждён, `AI Moderation` не стартует и ничего не выпускает; сохраните файл для разбора.
- Ключи и реальные сообщения провайдерам не попадают в репозиторий и документацию.
