# Дизайн и оформление

Источник палитры и шрифтов — `packages/design`; общие компоненты — `packages/ui`.
Интерфейсы русские, светлые: синяя внешняя область, светлая поверхность,
крупная типографика и ясное главное действие. Unbounded — акценты (обычно 400),
Arial — системный основной текст. Один локальный Unbounded Variable WOFF2
покрывает веса 200–900; выбранные веса задаются в CSS потребителей;
сохранять OFL и встроенные лицензионные уведомления автономных HTML/CSS.

Проверять клавиатуру, видимый фокус, контраст, увеличенный текст и ширины
320/390/540 px. Статусы сообщают смысл текстом, не только цветом. Loading
сохраняет подпись и ширину кнопки; ошибка не теряет ввод. Обложка категории
Stream Info сохраняет название и placeholder при загрузке/ошибке; устаревший
ответ не заменяет новую категорию.

## Движение

Токены находятся в `packages/design/tokens.css`: короткий отклик, лёгкая
упругость, быстрое восстановление резкости (до 120 мс). Hover не двигает цель.
Не добавлять постоянные JS-циклы и полноэкранные blur-подложки.
`prefers-reduced-motion` отключает необязательное движение; существующие явные
эфирные overrides сохраняются. Фокус и статус доступны без анимации.

Сохранять режимы, тайминги, два текстовых слоя и ретраи Tuna. Провайдер владеет
удалением сообщений/alerts: reduced-motion не меняет задержку скрытия чата,
blur дочернего текста не должен преждевременно завершать перекат донатеров.
Проверять прерывание переходов, быстрые повторные действия и смену reduced-motion.

## Artwork

Геометрия сцен — `artwork/scenes/layout.json`; утверждённые аватар и QR сохранять.
Генераторы запускаются явно из корня: `bun run render:logo`, `bun run render:scenes`
и `bun run render:artwork <группа>` (`banners`, `panels`, `wallpapers`, `brand`, `favicon`).
Без группы `render:artwork` создаёт все изображения, кроме логотипа и сцен;
`bun run render:all` выполняет полный экспорт. Сначала изменить источник,
затем пересобрать нужный экспорт.

Настройка сцен: [artwork/scenes/SETUP.md](../artwork/scenes/SETUP.md).

Готовые экспорты находятся в `dist/artwork/` и не хранятся в Git. Растры
экспортируются и просматриваются в согласованной Linux-среде. При изменении
шрифта, геометрии или среды просмотра проверить новые изображения; не принимать
расхождения вслепую. Размеры, внешний вид и независимость готовых файлов
проверять вручную; линтеры исходной разметки и шрифтов остаются в `bun run check`.
Сборка не доказывает приёмку в OBS CEF или установку CSS провайдера.
