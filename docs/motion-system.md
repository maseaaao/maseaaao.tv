# Движение интерфейса

Доработка 22.10.2026 продолжает послойное появление музыки, перекат донатеров
и редкую волну соцсетей из коммитов `f9f059e` / `eed2684`.
Ориентиры — [Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion)
и [Windows Motion](https://learn.microsoft.com/en-us/windows/apps/design/motion/):
движение связывает состояния и подтверждает действие. Значения ниже — собственная
настройка проекта, а не копия системных таймингов.

## Характер

Светлые поверхности, синий акцент, Unbounded и Arial сохраняются. Неподвижный фон
даёт точку отсчёта; содержимое проходит небольшое расстояние и спокойно останавливается.
Не добавлять бесконечные пульсации, параллакс, размытие, тряску ошибок или отскоки.
Не анимировать ввод текста, каждый результат поиска и каждый сетевой опрос.

Общие параметры находятся в `packages/design/tokens.css`:

| Событие                    | Время  | Поведение                                      |
| -------------------------- | ------ | ---------------------------------------------- |
| Нажатие                    | 90 мс  | Смещение кнопки на 1 px, размер цели неизменен |
| Смена состояния            | 160 мс | Цвет/граница без движения текста               |
| Появление                  | 240 мс | Быстрое начало, мягкая остановка               |
| Закрытие                   | 140 мс | Короткий уход, управление освобождается сразу  |
| Первое знакомство с сайтом | 360 мс | Три смысловые группы, задержки 0/30/60 мс      |

Кнопки возвращаются за 240 мс. `AppButton.pressEffect=false` отключает смещение.
Кривые монотонные, без перелёта конечной позиции. CSS transitions при повторном
нажатии продолжаются из текущего состояния; очереди эффектов не создаются.

## Продукты

- **Сайт:** появление с 65% непрозрачности и 6 px; подложка стоит на месте.
  При клавиатурном фокусе вступление сразу завершается. Ссылки доступны без JS.
  После 420 мс фоновой анимации нет.
- **Stream Info:** настройки проявляются с 8 px и масштабом 0,99; закрываются
  с 4 px и масштабом 0,995. Уходящий слой сразу получает inert/aria-hidden,
  фокус возвращается кнопке. Поиск, новые теги и уведомления появляются с 4 px.
  Удаление результатов и уведомлений немедленное, без задержки доступности.
  Поля и закреплённая панель применения не перемещаются.
- **Музыка:** сохранены установленная послойная механика, смена текста до 280 мс,
  параметры URL, таймеры показа и ограниченные ретраи обложек. Кривая обложки
  использует общий токен. Системное уменьшение движения теперь учитывается
  во время работы: активные переходы завершаются в целевом состоянии, последняя
  версия текста сохраняется. `motion=1` по-прежнему явно разрешает движение в OBS.
- **Чат:** вход 300 мс, путь уменьшен с 12 до 8 px, остановка согласована с музыкой.
  При уменьшенном движении сообщение появляется сразу. Уход 500 мс и задержка
  скрытия принадлежат прежнему жизненному циклу провайдера.
- **Донатеры / соцполоса:** существующие 520 мс и редкая волна раз в 30 секунд
  сохранены. Повторные эффекты поверх них не добавлены.
- **Сцены OBS:** Move/Transition Table в этом изменении не перенастраивались.
  Это отдельная пространственная система, а не CSS-анимация сайта.

Системное уменьшение движения отключает перемещения сайта и дока. Для эфира
сохраняются только уже существующие явные исключения; новые не устанавливаются.
Фокус, ошибки и статус сохранения остаются видимыми без анимации.

## Проверка и подключение

Сборки: `build:website`, `build:stream-info`, `build:tuna`, `build:widgets`.
Проверки: `npm run check`, `npm run test:stream-info`, браузерные тесты
`motion-system`, `stream-info-delivery`, `landing-corrections`, `tuna-widget`,
`donors-slide`, `streamlabs-chat-design` в `tests/*.test.mjs`.

Тесты используют подставные данные, не запускают эфир, музыку и Actions.
Проверять также быстрый Escape во время появления, повторное открытие, Tab,
320/390/540 px, увеличенный текст и смену reduced-motion во время перехода.

До пересборки прямых ресурсов сохранены прежние dist в
`../Streamer.bot/backup/motion-system-20261022/`.
Текущие локальные пути OBS/Stream Info ведут в dist приложений; уже открытые
страницы требуют перезагрузки для загрузки новых файлов. Сборка не подтверждает
приёмку в OBS CEF. CSS чата требуется отдельно перенести в Streamlabs:
локальный экспорт и обычный OBS override не заменяют анимации аккаунта.
Публичный сайт требует отдельной публикации; она в эту работу не входит.
