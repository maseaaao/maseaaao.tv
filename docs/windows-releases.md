# Готовые релизы для Windows

Разработка и сборки выполняются в Linux/WSL2. Windows получает опубликованный бандл GitHub Releases; для работы установленного комплекта WSL и доступ к GitHub не нужны. Обновлятор требует Python 3.10+ в Windows, без pip-зависимостей. PowerShell 5.1+ запускает его без Node/Bun.

## Формат релиза

Один релиз `vX.Y.Z` на весь репозиторий. В нём `maseaaao-X.Y.Z.zip` — единый архив, где каждый продукт лежит в своей папке (`stream-info/`, `artwork/`, `website/` и т.д.), плюс `maseaaao-X.Y.Z.manifest.json` и `SHA256SUMS`. Обновлятор находится в папке `updater/` внутри общего архива. Обновлятор скачивает архив один раз и извлекает из него только выбранные продукты.

## Первый запуск

Из релиза скачать `maseaaao-X.Y.Z.zip`, сверить его SHA256 с `SHA256SUMS` этого релиза и распаковать папку `updater/` в постоянную папку Windows, например `D:\StreamRuntime\updater`. Архив содержит Python-код, PowerShell-обёртки, каталог продуктов и эту инструкцию. При работе из исходников используются те же файлы в `tooling/windows`; каталог читается из `tooling/release-products.json`.

Выбрать отдельную пустую папку установки, например `D:\StreamRuntime\maseaaao.tv`. Допустима `.runtime` внутри **Windows-копии** репозитория: она исключена из Git. Папка внутри checkout WSL остаётся в WSL независимо от `.gitignore`; её не следует использовать для рабочего стрима. В корень установки нельзя класть свои файлы до инициализации. Пользовательские базы, настройки, секреты и резервные копии приложений остаются в прежних каталогах.

```powershell
# План: все продукты последнего бандла.
.\Update-All.ps1 -Root 'D:\StreamRuntime\maseaaao.tv'

# Скачать бандл и установить все продукты полностью.
.\Update-All.ps1 -Root 'D:\StreamRuntime\maseaaao.tv' -Apply

# Только один продукт; без -Apply снова будет план.
.\Update-Releases.ps1 -Root 'D:\StreamRuntime\maseaaao.tv' -Product artwork -Apply

# Конкретная версия бандла, например для первой установки или закреплённого комплекта.
.\Update-Releases.ps1 -Root 'D:\StreamRuntime\maseaaao.tv' -All -Version 1.0.0 -Apply
```

Без `-Root` используется `%LOCALAPPDATA%\maseaaao.tv\runtime`. Без выбора режима `Update-Releases.ps1` также выбирает все продукты. Если политика PowerShell запрещает скрипты, запускать Python напрямую; системную политику изменять не требуется:

```powershell
python .\update_releases.py --all --root 'D:\StreamRuntime\maseaaao.tv' --apply
```

Для приватного репозитория задать `GH_TOKEN` или `GITHUB_TOKEN` в окружении процесса с правом чтения Contents. Токен не хранится в runtime и не передаётся на другой хост при перенаправлении скачивания. Публичный репозиторий не требует токена, но ограничения GitHub API всё равно действуют.

## Выбор версии

Обновлятор читает все страницы GitHub Releases и выбирает наибольший стабильный бандл `vX.Y.Z`. Черновики, prerelease и теги других форматов исключены. `-Version` закрепляет точную версию бандла. Отсутствующий архив или манифест у выбранного релиза — ошибка всего обновления, без скрытого перехода на старую версию.

Версии продуктов внутри бандла независимы и записаны в его манифесте; обновлятор сравнивает файлы продукта, поэтому новый общий релиз не требует ручного повышения всех внутренних версий. Неявное понижение версии продукта запрещено; для возврата комплекта используется откат.

## Структура и установка

```text
runtime/
  current/
    installed.json
    stream-info/change-info-streamer-bot.ru.html
    stream-info/streamerbot-import.txt
    tuna-widget/obs-tuna-widget.html
    obs-widgets/social-strip/index.html
    obs-widgets/sounds/...
    artwork/scenes/...
    artwork/logo/...
    system-microphone/*.tgz
    voice-stream/*.tgz
    windows-integrations/yandex-music/control.ps1
    windows-integrations/start-companion.ps1
    windows-integrations/diagnostics/...
    windows-integrations/actions/...
    website/...
  packages/<product>/<version>/...
  previous/<snapshot>/...
  .staging/...
```

Каталог продукта заменяется полным новым комплектом: удалённые из релиза файлы не остаются в `current`. Перед переключением скачивается и проверяется архив бандла и каждый устанавливаемый файл: размер, SHA256, точный перечень, пути Windows, отсутствие ZIP-ссылок и выхода за каталог. Неизвестные файлы и локальные изменения в прежнем `current` блокируют обновление, чтобы их не потерять. `current` управляется обновлятором; пользовательские файлы хранить отдельно.

Для переключения каталогов требуется доступ Windows к их переименованию. Это два переименования с журналом восстановления, **не атомарная транзакция файловой системы и не обещание бесшовного обновления во время эфира**. Применять в окно обслуживания; при блокировке файлов закрыть соответствующее приложение штатно и повторить. Не завершать процессы принудительно. Скачанные файлы сами по себе не перезагружают браузерные источники.

Блокировка предотвращает два одновременных обновления. Ошибка скачивания/проверки оставляет текущую установку на месте. Предыдущий полный комплект сохраняется в `previous`, его имя выводится после установки. История и скачанные пакеты автоматически не удаляются.

```powershell
.\Update-Releases.ps1 -Root 'D:\StreamRuntime\maseaaao.tv' -Rollback 'ИМЯ_СНИМКА' -Apply
# После аварийного завершения во время переключения:
.\Update-Releases.ps1 -Root 'D:\StreamRuntime\maseaaao.tv' -Recover -Apply
```

Откат восстанавливает весь комплект и сохраняет заменённый комплект как новый снимок. После сбоя `-Recover` возвращает прежний каталог, если переключение прервалось между переименованиями, или завершает журнал, если новый каталог уже подключён. Остатки `.staging` после аварийного завершения сохраняются для разбора. Junction/символические ссылки в runtime не поддерживаются.

## Первоначальное подключение приложений

Обновлятор не переводит текущие приложения автоматически. Перед миграцией сохранить затронутые настройки и штатные экспорты; менять пути через владельца данных или при корректно закрытом приложении. Сохранять ID, размеры, размещение и URL-параметры.

| Потребитель                              | Новый стабильный путь относительно runtime                                                     |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------- |
| OBS — фоны и логотипы                    | `current/artwork/scenes`, `current/artwork/logo`                                               |
| OBS — музыка                             | `current/tuna-widget/obs-tuna-widget.html` + прежние URL-параметры                             |
| OBS — соцполоса и прозрачное изображение | `current/obs-widgets/social-strip/`                                                            |
| Док INFO и HTTP-маппинг Stream Info      | `current/stream-info/`                                                                         |
| C# уведомления и OBS Health              | `current/obs-widgets/sounds/`                                                                  |
| C# Яндекс Музыки                         | `current/windows-integrations/yandex-music/control.ps1`                                        |
| Запуск Companion                         | `current/windows-integrations/start-companion.ps1 -StreamerbotRoot <установка>`                |
| Диагностика                              | `current/windows-integrations/diagnostics/check-stream-stack.ps1 -StreamerbotRoot <установка>` |

Выполнить компиляцию изменённых Execute Code внутри Streamer.bot. Модули Companion импортировать штатно из `.tgz`, затем выбрать версию в существующих соединениях с сохранением настроек. Импорт C#, установка модулей и provider CSS — отдельные операции. `installed.json` показывает версии **файлов**, а не загруженных Actions/модулей. Откат файлов также не откатывает импортированный C# или выбранную в Companion версию.

После подключения проверить реальные пути и отображение в OBS, загрузку INFO/HTTP, версии модулей и ссылки Actions чтением состояния. Эфир, сцены, mute, музыку и сообщения не менять ради диагностики. Удалять прежнюю Windows-копию репозитория можно только после проверки всех потребителей, включая ярлыки и остальные коллекции OBS.
