# Готовые релизы для Windows

Разработка и сборки выполняются в Linux/WSL2. В Windows готовый комплект
устанавливается вручную из GitHub Releases. OBS, Streamer.bot и Companion
устанавливаются отдельно; их рабочие данные остаются в прежних каталогах.
Для диагностики используется комплектный Node Companion (Node 22.13+).

## Формат релиза

Один релиз `vX.Y.Z` на весь репозиторий. В нём один архив
`maseaaao-X.Y.Z.zip` с папками продуктов, инструкцией `INSTALL.md` и лицензиями.
Рядом публикуется `SHA256SUMS`. Автоматического обновлятора и отдельного
манифеста установки нет. Внутренние версии модулей Companion сохраняются
для штатного TGZ-импорта.

## Установка и обновление

1. Выбрать нужный опубликованный выпуск `vX.Y.Z` и скачать его ZIP и
   `SHA256SUMS`. Для приватного репозитория войти в GitHub через браузер.
2. Сверить SHA256 скачанного ZIP со строкой из `SHA256SUMS` этого же выпуска:

   ```powershell
   Get-FileHash -Algorithm SHA256 '.\maseaaao-1.0.0.zip'
   ```

3. Распаковать архив в новый пустой каталог Windows. Не распаковывать поверх
   прежнего комплекта: так удалённые из выпуска файлы не останутся рядом с новыми.
   WSL-пути не подходят для постоянных ресурсов работающих Windows-приложений.
4. Перед заменой сохранить прежний комплект, изменённые вручную ресурсы и
   штатные экспорты затронутых приложений. Пользовательские базы, настройки,
   токены и резервные копии хранить отдельно от папок продуктов.
5. В окно обслуживания подключить новые ресурсы через интерфейсы приложений.
   Если нужно сохранить прежний постоянный путь, сначала штатно закрыть
   приложения, использующие файлы, переименовать прежнюю папку для отката,
   затем переместить новый комплект на прежний путь. Это ручные операции,
   без автоматического восстановления и бесшовного обновления во время эфира.
6. Проверить реальные пути, отображение ресурсов, загрузку Stream Info и
   версии импортированных модулей. Скачивание и распаковка сами по себе
   не перезагружают браузерные источники и не устанавливают C# или TGZ.

Пример структуры распакованного комплекта:

```text
maseaaao.tv/
  INSTALL.md
  LICENSE
  stream-info/change-info-streamer-bot.ru.html
  stream-info/streamerbot-import.txt
  tuna-widget/obs-tuna-widget.html
  obs-widgets/social-strip/index.html
  obs-widgets/sounds/...
  artwork/scenes/...
  artwork/logo/...
  system-microphone/*.tgz
  voice-stream/*.tgz
  windows-integrations/yandex-music/control.ps1
  windows-integrations/start-companion.ps1
  windows-integrations/diagnostics/...
  windows-integrations/actions/...
  website/...
```

## Подключение приложений

Менять пути через владельца данных или при корректно закрытом приложении.
Сохранять ID, размеры, размещение, URL-параметры и настройки соединений.
Пути ниже заданы относительно корня распакованного комплекта.

| Потребитель                              | Путь                                                                                   |
| ---------------------------------------- | -------------------------------------------------------------------------------------- |
| OBS — фоны и логотипы                    | `artwork/scenes/`, `artwork/logo/`                                                     |
| OBS — музыка                             | `tuna-widget/obs-tuna-widget.html` + прежние URL-параметры                             |
| OBS — соцполоса и прозрачное изображение | `obs-widgets/social-strip/`                                                            |
| Док INFO и HTTP-маппинг Stream Info      | `stream-info/`                                                                         |
| C# уведомления и OBS Health              | `obs-widgets/sounds/`                                                                  |
| C# Яндекс Музыки                         | `windows-integrations/yandex-music/control.ps1`                                        |
| Запуск Companion                         | `windows-integrations/start-companion.ps1 -StreamerbotRoot <установка>`                |
| Диагностика                              | `windows-integrations/diagnostics/check-stream-stack.ps1 -StreamerbotRoot <установка>` |

Выполнить компиляцию изменённых Execute Code внутри Streamer.bot.
Модули Companion импортировать штатно из `.tgz`, затем выбрать версию
в существующих соединениях с сохранением настроек. Перед установкой пройти
[проверки Companion](../integrations/companion/README.md). Импорт C#, установка
модулей и provider CSS — отдельные операции.

Эфир, сцены, mute, музыку и сообщения не менять ради диагностики.
Не редактировать живые базы при работающем владельце. Удалять прежний комплект
можно только после проверки всех потребителей, включая ярлыки и коллекции OBS.

## Откат

Сохранить новый комплект отдельно и вернуть прежнюю папку либо прежние пути
ресурсов через интерфейсы приложений. Если файлы заблокированы, штатно закрыть
соответствующее приложение; не завершать процессы принудительно.

Возврат файлов не откатывает импортированный C# и выбранную в Companion версию.
Их вернуть отдельно в существующих Actions и соединениях. При необходимости
восстановить совместимый штатный экспорт средствами приложения; не копировать
базу поверх работающего владельца.

## Выпуск для разработчика

Один тег `vX.Y.Z`, один выпуск, один архив `maseaaao-X.Y.Z.zip`.
Модули Companion сохраняют свои версии для TGZ-импорта, отдельные GitHub-релизы
им не нужны.
1. Добавить описание выпуска в корневой `CHANGELOG.md` под `## X.Y.Z`.
2. Проверить исходники и тесты: `bun run check` и `bun run test`.
3. Собрать и проверить комплект локально инструментами из корневого README:

   ```bash
   bun run test:releases
   node tooling/bundle-release.mjs --build v1.0.0
   node tooling/bundle-release.mjs v1.0.0
   ```

   Результат: `build/release/v1.0.0/`. Диагностика собирается в самостоятельный
   `.mjs` с ZIP-библиотекой и её лицензией; `node_modules` для неё не требуется.
4. По отдельному поручению закоммитить изменения, создать тег на этом коммите
   и отправить его. Workflow `Release` собирает комплект и создаёт черновик.
5. Проверить архив и по отдельному поручению опубликовать черновик в GitHub Releases.

Существующий выпуск не перезаписывается. Для исправления опубликованного
комплекта выпустить новую версию. Релиз не публикует сайт в Cloudflare
и не меняет работающие OBS, Streamer.bot или Companion.
