# Архитектура

pnpm workspaces объединяет самостоятельные продукты без общей версии. Исходники приложений — в apps, автоматизации — в integrations. Пользовательские базы, токены, настройки программ и резервные копии остаются вне Git.

Общая палитра — packages/design/brand.css. В проекте распространяется только Unbounded: исходный TTF и веб-шрифт 400/600 WOFF2; приоритетные браузерные потребители используют 400. Arial берётся из системы. Шрифт и лицензия встраиваются в автономные HTML/CSS; сайт получает только нужный WOFF2 и лицензию.

apps/website/src — исходный сайт, apps/website/public — неизменяемая статика; dist — отслеживаемая публикация Cloudflare. Подготовка очищает каталог публикации и создаёт его заново. Stream Info выпускает один русский HTML, Tuna — один HTML с локальными зависимостями внутри.

artwork/scenes/layout.json — единственный источник геометрии сцен. Генератор использует его при подготовке HTML и WEBP; тесты проверяют прозрачность, QR и размеры. OBS использует окончательные пути artwork. Обои имеют две ориентации 4K; утверждённый исходник логотипа сохраняется без изменения.

Библиотеки модулей Companion собираются из закреплённых NuGet-версий и входят в пакет. Тип аудиоустройства и ID Actions задаются явно; код не подставляет старые имена Actions. Защита удержанием кнопки, таймауты, ограничения и проверка статуса OBS сохраняются.

Браузерные продукты собираются Vite. Каждый standalone HTML имеет отдельный output; CSS провайдеров собирается PostCSS. Исходники OBS-виджетов — src, итоговые автономные ресурсы — dist. Подробнее: [сборочная инфраструктура](build-toolchain.md).

Главная страница сайта не содержит Twitch iframe/чата и не запрашивает статус эфира. Функции ручного создания видео сохранились только в `check.html`. Для LIVE требуется отдельно разрешённый серверный источник с закрытыми Twitch credentials; этот backend не входит в текущую статическую сборку.

Планировщик — закреплённый Turbo. Пакеты экспортируют исходники, поэтому транзитная задача `source` реализована в каждом пакете (`tooling/source-task.mjs`): она суммирует исходники пакета и ничего не собирает, поэтому изменение общего пакета распространяется на всех его потребителей без фиктивной сборки библиотек. `build` и `check` принадлежат продуктам; каталог UI явно зависит от сборок OBS provider exports и импорта Stream Info. Artwork использует QR сайта, а сайт копирует готовые raster assets: это отдельное файловое ребро, не циклическая зависимость пакетов. Полный приёмочный запуск рендерит artwork до сборки сайта.
