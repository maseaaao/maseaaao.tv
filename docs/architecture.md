# Архитектура

npm workspaces объединяет самостоятельные продукты без общей версии. Исходники приложений — в apps, автоматизации — в integrations. Пользовательские базы, токены, настройки программ и резервные копии остаются вне Git.

Общая палитра — packages/design/brand.css. В проекте распространяется только Unbounded: исходный TTF и веб-шрифт 600 WOFF2. Arial берётся из системы. Шрифт и лицензия встраиваются в автономные HTML/CSS; сайт получает только нужный WOFF2 и лицензию.

apps/website/src — исходный сайт, apps/website/public — неизменяемая статика; dist — отслеживаемая публикация Cloudflare. Подготовка очищает каталог публикации и создаёт его заново. Stream Info выпускает один русский HTML, Tuna — один HTML с локальными зависимостями внутри.

artwork/scenes/layout.json — единственный источник геометрии сцен. Генератор использует его при подготовке HTML и WEBP; тесты проверяют прозрачность, QR и размеры. OBS использует окончательные пути artwork. Обои имеют две ориентации 4K; утверждённый исходник логотипа сохраняется без изменения.

Библиотеки модулей Companion собираются из закреплённых NuGet-версий и входят в пакет. Тип аудиоустройства и ID Actions задаются явно; код не подставляет старые имена Actions. Защита удержанием кнопки, таймауты, ограничения и проверка статуса OBS сохраняются.

Браузерные продукты собираются Vite. Каждый standalone HTML имеет отдельный output; CSS провайдеров собирается PostCSS. Исходники OBS-виджетов — src, итоговые автономные ресурсы — dist. Подробнее: [сборочная инфраструктура](build-toolchain.md).
