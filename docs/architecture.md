# Архитектура

npm workspaces объединяет самостоятельные продукты без общего номера версии. Протокол Stream Info, C# API, имена HTML и формат импорта сохранены. Общая тема только светлая.

`packages/design/brand.css` — общая палитра, `fonts` — единственные редактируемые шрифты, `licenses` — лицензии. Stream Info импортирует CSS и встраивает ресурсы в HTML; сайт получает копию при подготовке публикации; оформление использует общий CSS; Tuna встраивает свои шрифты при сборке. Геометрия и поведение остаются в продуктах; отдельный пакет UI пока не нужен.

Редактируемый сайт находится в `apps/website/public`. `build:website` очищает строго корневой `dist` и готовит публикацию с прежними URL. `dist` хранится в Git для существующего Cloudflare-подключения, которое уже публиковало его без обязательной сборки. CI проверяет совпадение с подготовленными источниками.

`artwork` содержит шаблоны, карту сцен и экспорты. Прозрачные игровые зоны сохраняются. Синие обои — фирменный фон, а не тёмная тема. Тёмный комплект OBS/Tuna исключён из нового рабочего дерева; прежние версии доступны в истории.

`integrations/streamerbot` содержит исходники, а не data/actions.json. `integrations/companion` содержит два модуля, общий контроллер процесса и сборку. Библиотеки загружаются из закреплённых NuGet-версий, независимо от установленного Streamer.bot. Пакеты устанавливаются отдельно с сохранением соединений и ID.

Приватные настройки и приложения остаются вне Git. Локальное обновление поддерживает прежние пути OBS и резервирует заменяемые файлы. Игровые пресеты сохранены как C# и ресурсы. Разовые установщики, RPC-мутации, снимки и старые скрипты восстановления не включаются в автоматическую сборку; оригиналы остаются в установленной папке и backup.
