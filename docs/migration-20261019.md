# Перенос 19.10.2026

## Выполнено локально

Stream Info и Get Brand Colors импортированы через git subtree без squash. Исходные коммиты входят в историю main; SHА записаны в migration-sources.json. Локальный Stream Info сверён с origin/main: расхождений нет. Исходный main сайта — предок нового main, чужих изменений при проверке fetch не обнаружено.

Сайт перемещён в apps/website/public, оформление — artwork, общий дизайн и шрифты — packages/design. Добавлены Tuna, остальные OBS-ресурсы, исходники двух модулей Companion, DonationAlerts, Яндекс Музыки, OBS Health, игровые пресеты и поддерживаемая диагностика. Происхождение выбранных файлов — migration-files.json (хеши исходных копий до адаптации путей, форматирования и удаления секрета).

Светлое оформление сохранено везде; переключатели, тёмные комплекты и их снимки удалены из поддерживаемой версии. Редактор палитр продолжает генерировать образцы разных цветов, управляющий интерфейс светлый. Прежние ресурсы src/assets на рабочем компьютере сохранены как игнорируемые копии для существующих путей OBS.

Настроены один lockfile, явные команды продуктов, проверки PR/main без автокоммитов, независимые теги и создание проверяемых черновиков релизов. Старый Wrangler и корневой dist сохранены как контракт Cloudflare. Добавлен каталог инструментов с собственными версиями, без ссылок на ещё не опубликованные артефакты.

В DonationAlerts найден встроенный OAuth client secret: в новую историю он не попал. Новому исходнику нужна приватная глобальная переменная daClientSecret. Установленная интеграция не менялась. Версии подготовлены: Stream Info 1.3.3 и Tuna 1.0.0; теги не создавались.

Не переносились базы, настройки аккаунтов, data/actions.json, логи, backup, экспорты, установленные модули, архивы прошлых версий и разовые мутационные/восстановительные скрипты. Эти оригиналы сохранены в рабочей установке. Общая документация установки Streamer.bot обновлена указателем на новые исходники.

- Полный npm test на Node 22.23.3: 84 проверки сайта/OBS-ресурсов/локального копирования, 78 JS-проверок Stream Info, C# cache/category suites и 10 общих ranking fixtures, четыре набора Companion и три SQLite-теста — успешно.
- Редактор палитр: избранное, перезагрузка, история, импорт/экспорт, 10000 записей, пять размеров, светлый интерфейс при тёмной теме ОС — успешно.
- check:stream-info, build:stream-info: импорт и четыре автономных локализованных HTML проверены.
- build:website и check: структура, локальные зависимости оформления и побайтовое совпадение публикации — успешно.
- render:scenes: заново сформированы 12 светлых экспортов; свежие PNG и lossless WEBP совпали. Исходная проверка до переноса имела один сбой из-за старого локального render report.
- Tuna: автономная сборка, встроенные шрифты/лицензии, смена playing/pause с подставным API — успешно.
- Оба модуля Companion собраны с библиотеками закреплённых NuGet-версий и упакованы в tgz без установки.
- Семь C#-модулей скомпилированы против библиотек установленного Streamer.bot; это отдельная компиляция, не запуск Execute Code в приложении. Предупреждения о скрытии методов относятся к адаптеру CPHInlineBase этой проверки.
- ZIP Stream Info и Tuna локально упакованы, прочитаны и сверены с HTML. GitHub download-проверка предусмотрена workflow, но реальный релиз не создавался.
- Обновление локальных ресурсов проверено на отдельной тестовой папке: dry run, резервирование, повторное применение без изменений и сохранение посторонних данных. На живой установке --apply не выполнялся.

## Проверка чистой копии

Создан отдельный git clone без старых node_modules и игнорируемых src/assets. На Node 22.23.3 успешно выполнены npm ci по lockfile, build:website, check, check:stream-info, build:stream-info, build:tuna, полный npm test и тест редактора палитр. В наборе браузерных/ресурсных проверок 83 успешных и одна ожидаемо пропущенная проверка необязательных локальных render-report PNG; в основной рабочей копии прошли все 84.

Первое сравнение выявило влияние CRLF на сжатый импорт C#: генератор теперь нормализует исходники перед упаковкой, Tuna нормализует HTML и лицензии. После исправления чистая копия повторно собрала продукты; git diff остался пустым, все отслеживаемые артефакты воспроизводятся. Повторно прошли проверки команд генераторов, автономного Tuna и резервирования локального обновления. Команда full теперь готовит общие ресурсы до рендера и публикацию после него; полный массовый рендер всех ресурсов не запускался.
