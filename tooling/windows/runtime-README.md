# Windows integrations

Эти файлы предназначены для Windows. Скачивание не меняет Actions, настройки OBS или Companion.

`actions/` содержит поддерживаемые C#-шаблоны интеграций и их инструкции для ручного обновления существующих Execute Code. Это код для среды Streamer.bot, не отдельные исполняемые файлы. Пути к ресурсам в шаблонах требуют настройки под выбранный runtime; скачивание шаблонов не меняет уже загруженный C#.

Перед запуском задайте `STREAMERBOT_ROOT` — полный Windows-путь к установленному Streamer.bot. Для `start-companion.ps1` и `diagnostics/check-stream-stack.ps1` также можно передать `-StreamerbotRoot`. Не полагайтесь на расположение соседних папок после установки релиза.

`yandex-music/control.ps1` вызывается существующим Action с аргументом `-Command`; сохраняйте раздельные play/pause и ID Actions. При первоначальном подключении замените ссылку в исходнике и установленном C# на путь в runtime, затем проверьте компиляцию Execute Code.

Диагностика использует комплектный Node Companion и установленный Python. Контроллер музыки требует запущенную Яндекс Музыку с медиасессией; запускатель Companion требует существующие рабочие данные. Эти программы и данные не входят в релиз.

Установка вручную: распакуйте единый ZIP в новый каталог и следуйте INSTALL.md в его корне. Старый каталог сохраните для отката; автоматического обновлятора нет.
