# Политика безопасности

Политика относится ко всему репозиторию maseaaao.tv: сайту, виджетам, интеграциям и инструментам установки и обновления.

О предполагаемых уязвимостях сообщайте через [приватную форму GitHub](https://github.com/maseaaao/maseaaao.tv/security/advisories/new), а не через публичный Issue. Приложите минимальное воспроизведение, затронутую версию или коммит, влияние и, если возможно, вариант исправления.

Не присылайте OAuth-токены, секреты приложений, пароль WebSocket Streamer.bot, ID приватного канала, рабочие базы или полный Import-экспорт с учётными данными. HTML-интерфейс Stream Info спроектирован так, чтобы не получать Twitch OAuth-данные.

Исправления безопасности поддерживаются для актуальной ветки `main` и последнего общего релиза. Для готовых файлов используйте пересобранную версию из исправленного выпуска.
